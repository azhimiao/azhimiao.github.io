对于必须以单独确认方式提示的异常条款，我们将在注册、购买或首次启用相关能力时，以显著方式另行提示；该提示与本协议共同构成约定内容。

## TOS-2 本地软件、开源组件与可选云端能力是不同层级

Nyra 的产品形态分为：

1. **本地软件 / 客户端**：用户自愿下载并在自己的设备上运行；
2. **开源或可查看源码的组件**：按其仓库中标明的具体开源许可证使用；
3. **可选在线能力**：例如账户、同步、托管接口、模型路由、生图、语音或其他计算能力；
4. **第三方 / BYOK 能力**：由用户选择第三方模型或提供自己的 API Key。

开源代码的许可证条款优先适用于相应开源组件；本协议主要规范 Nyra 品牌产品、非开源组件、官方分发、账户、在线能力及付费数字资源。

**“提供可下载软件”不等于承诺提供持续人工服务。** 除具体购买页面明确说明外，下载或使用 Nyra 不包含人工部署、人工调试、远程维护、数据恢复、角色定制、长期兼容支持或指定响应时间。
