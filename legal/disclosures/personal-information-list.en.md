# Personal Information Collection List (publication template)

| Category | Examples | Purpose | Required? | Suggested retention | Sensitivity |
|---|---|---|---|---|---|
| Account | Email, username, account ID | Login, recovery, security | Core account | Account + required legal period | Usually ordinary |
| Age | DOB/age band, 18+ status | Eligibility/safety | Companion required | Account lifetime | May be sensitive |
| Emergency contact | Name/label, phone/email | Severe safety response | Region/mode dependent | Until removed/account closes | Sensitive |
| Character card | Name, appearance, persona | Character operation | Feature dependent | User-controlled | May be sensitive |
| Relationship/preferences | Relationship type, First Light, boundaries | Personalization | Companion feature | User-controlled | May be sensitive |
| Chat/diary | Text, files | Conversation/history | Feature dependent | User-controlled | Potentially highly sensitive |
| Voice | Audio/transcript | Voice mode | Feature dependent | Short/user-controlled | Potentially sensitive |
| Media | Uploads/generated media | Multimodal generation | Feature dependent | User-controlled | Potentially sensitive |
| Memory | Summaries/long-term preferences | Continuity | Configurable | User-controlled | Potentially sensitive |
| Device/diagnostics | App version, crash data | Reliability/security | Minimal necessary | 30–180 days suggested | Usually ordinary |
| Security logs | Login/risk/enforcement | Anti-fraud/security | Necessary | 6–24 months by risk | May be sensitive |
| Payments | Order, amount, currency, status | Billing/refunds | Paid users | Tax/dispute period | Financial-related |
| API config | Provider, key/token | BYOK | BYOK users | User-controlled | High-risk credential |

Replace suggested retention with actual implementation values before publication.
